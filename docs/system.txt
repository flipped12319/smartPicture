一、系统组成
智能云图库由三部分组成：Vue3 前端、Java Spring Boot 后端、Python LangGraph 智能体服务。

二、主要功能
1. 用户可以在公共图库中浏览、搜索图片。
2. 用户可以创建自己的私人空间，上传和管理图片。
3. 图片支持分类与标签，便于检索。
4. 管理员可以审核图片、管理用户与空间。
5. 智能助手可以分析图片内容、上传图片、搜索图片、删除私人图库中的图片，
   还可以把故事文本与图片合成为 PDF 文件。
6. 智能助手具备长期记忆能力，能够记住用户的偏好和重要事实。

三、图片审核
新上传到公共图库的图片默认处于待审核状态，需要管理员审核通过后才会对普通用户可见。
上传到私人空间的图片由空间创建者自动过审。

四、空间等级
空间分为普通版、专业版、旗舰版三个等级，不同等级的最大存储容量与图片数量上限不同。

五、智能助手可用工具
- analyze_images：基于多模态大模型分析图片内容
- upload_image：把图片上传到图库（公共图库或私人空间）
- search_images：按名称、分类、标签搜索图片
- delete_images：删除最近一次搜索到的私人图库图片
- create_pdf_from_story：把故事文本与图片合成为 PDF
- remember_info：把重要信息写入长期记忆
- recall_info：从长期记忆中检索历史信息
- retrieve_from_knowledge_base：从本知识库中检索系统相关说明
