## Project Overview

鱼皮云图库 (Yu Picture Cloud Gallery) — a Vue 3 picture gallery application with user auth, picture management, and team spaces. Backed by a Java/Spring Boot API at `http://localhost:8123`.

## Commands

```sh
npm run dev          # Start Vite dev server with hot-reload
npm run build        # Type-check then build for production
npm run type-check   # Run vue-tsc type checking only
npm run lint         # ESLint with auto-fix
npm run format       # Prettier format src/
npm run openapi      # Regenerate API client from backend OpenAPI spec
```

## Architecture

**Stack:** Vue 3 (Composition API, `<script setup>`), TypeScript, Vite 6, Ant Design Vue 4, Pinia, Vue Router 4, Axios.

**Path alias:** `@` → `src/`.

### API Layer (auto-generated)

The entire `src/api/` directory is generated by `@umijs/openapi` from the backend's Swagger docs (`http://localhost:8123/api/v2/api-docs`). Run `npm run openapi` to regenerate after backend API changes. Do not manually edit files in `src/api/`.

- **`src/request.ts`** — Custom Axios instance. Base URL `http://localhost:8123`, 60s timeout, `withCredentials: true`. Response interceptor redirects to `/user/login` when `code === 40100` (not logged in).
- **`src/api/typings.d.ts`** — All TypeScript types under the `API` namespace (request/response shapes, VO/entity types).
- **`src/api/{domain}Controller.ts`** — API functions per domain: `fileController`, `mainController`, `pictureController`, `spaceController`, `userController`.
- API response shape: `{ code: number, data: T, message: string }`. Code `0` = success.
- Function naming convention: `operationUsingMethod` (e.g., `getLoginUserUsingGet`, `listUserVoByPageUsingPost`).

### Routing & Permissions

- **`src/router/index.ts`** — Flat route table (no nesting). Admin routes are prefixed with `/admin`.
- **`src/access.ts`** — Global `router.beforeEach` guard. On first load, waits for `fetchLoginUser()` to complete before checking permissions. Routes starting with `/admin` require `loginUser.userRole === 'admin'`, otherwise redirects to `/user/login`.
- **`src/App.vue`** — App root. Fires `fetchLoginUser()` on mount, renders `<BasicLayout>`.

### Layout

- **`src/layout/BasicLayout.vue`** — Top-level layout: header (`GlobalHeader`), collapsible sidebar (`GlobalSider` when logged in), scrollable `<RouterView>` content area, fixed footer.
- **`src/components/GlobalHeader.vue`** — Logo/title bar, horizontal nav menu (filters admin items by user role), login button or user avatar dropdown with logout.
- **`src/components/GlobalSider.vue`** — Sidebar with "公共图库" (public gallery) and "我的空间" (my space) links. Only shown when user is logged in.

### State Management (Pinia)

- **`src/stores/useLoginUserStore.ts`** — Current user state (`loginUser` ref), `fetchLoginUser()` calls `getLoginUserUsingGet()`, `setLoginUser()` for local mutation.
- **`src/stores/counter.ts`** — Boilerplate counter store (unused in practice).

### Page Organization

- **`src/pages/HomePage.vue`** — Public gallery: search bar, category tabs, tag filters, paginated `PictureList`. Uses cached list endpoint.
- **`src/pages/user/`** — User-facing pages: login, register, create/edit picture, picture detail, create space, my space (auto-redirects to user's space or create page), space detail.
- **`src/pages/admin/`** — Admin pages: user management, picture management (with review), batch upload, space management.

### Reusable Components

- **`PictureList.vue`** — Grid of picture cards. Props: `dataList: PictureVO[]`, `loading: boolean`. Clicking a card navigates to `/picture/:id`.
- **`PictureUpload.vue`** — File upload via Ant Design's `<a-upload>`. Accepts JPG/PNG under 2MB. Props: `picture?`, `spaceId?`, `onSuccess?`.
- **`UrlPictureUpload.vue`** — URL-based picture upload. Input + submit button. Props: `picture?`, `spaceId?`, `onSuccess?`.

### Constants & Utils

- **`src/constants/picture.ts`** — Picture review status enum & label mappings (待审核/通过/拒绝).
- **`src/constants/space.ts`** — Space level enum & label mappings (普通版/专业版/旗舰版).
- **`src/utils/index.ts`** — `formatSize()` for file size formatting, `downloadImage()` using file-saver.
